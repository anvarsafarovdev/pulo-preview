# Pulo Preview

Designs of the Pulo Telegram Mini App, to try on real phones inside Telegram before they are built.
Made-up people and amounts only. Nothing here is the app's code or data.

- `index.html` — the list the preview bot opens.
- `d/` — one page per design.
- `tg.js` — uses Telegram's own bottom button, Back button, theme, viewport and vibration.
- `fonts/` — self-hosted fonts (SIL Open Font License 1.1, via Fontsource / Google Fonts).
